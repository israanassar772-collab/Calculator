# Calculator (آلة حاسبة)

A simple Windows Forms calculator built with C# on .NET Framework 4.7.2 in Visual Studio.

آلة حاسبة بسيطة مبنية بلغة C# باستخدام Windows Forms.

## Features / المزايا
- Enter two numbers and get their sum (addition).
- Shows a message if a field is left empty.

## Run / التشغيل
1. Open `WindowsFormsApp15.slnx` in Visual Studio.
2. Press **F5** to build and run.

## Tech
- C# / Windows Forms
- .NET Framework 4.7.2
